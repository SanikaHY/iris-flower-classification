1.Iris Flower Classification using Machine Learning

2.Project Overview

This project implements a Machine Learning model to classify Iris flowers into three species:

- Iris-setosa
- Iris-versicolor
- Iris-virginica

The classification is performed using the famous Iris dataset based on four flower measurements.

---

3. Dataset

The dataset contains **150 samples** with the following features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Target Variable:

- Species
